# CSCI4221
Software Engineering Class
EasyEatz is a recipe app that helps users find quick, affordable, and personalized meal ideas based on the ingredients they already have. The goal is to make cooking simple, fun, and accessible for everyone — especially students and busy individuals.
Kenzie’s Role: Recipe Writer: Creates and edits easy-to-follow recipes, writes user stories, and develops personas to represent target users. Works with the team to ensure the app’s content is clear, helpful, and beginner-friendly.
