## 1. My PBI for Project 3 (Kenzie – Data & Logistics)

**PBI Title:** Gather and organize recipe & nutrition data for the app

**User Story:**  
_As a user, I want the recipe app to have accurate recipes and nutrition information so that I can pick meals that fit my preferences and health goals._

**What I did / will do for this PBI:**

- Collect a set of recipes and their nutrition data (ingredients, calories, etc.).  
- Organize this data in a structured format (for example, JSON-style objects) so it can be loaded into the app.  
- Keep an updated spreadsheet for ingredient tracking so the team can see what data we already have.  
- Prepare the data so it can later be connected to the React Native Expo project (for example, imported into a data file or context).

**Acceptance Criteria:**

1. At least a basic set of recipes is collected (with ingredients and nutrition info).  
2. Data is stored in a consistent format that can be loaded by the app (for example, arrays of recipe objects).  
3. The ingredient/nutrition spreadsheet is updated and matches the data structure used in the app.  
4. Files are organized so other teammates (front-end and back-end) can easily access and use the data.
